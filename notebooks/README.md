# Notebooks de Análisis Exploratorio de Datos (EDA)

Por directriz estricta de arquitectura **CRISP-ML(Q)** del curso:
- Este directorio se utiliza **exclusivamente para Análisis Exploratorio de Datos (EDA)** e inspección visual preliminar.
- **Está prohibido** ubicar aquí la lógica final de preprocesamiento, entrenamiento, validación cruzada, selección de modelos o inferencia; toda la solución ejecutable reside de forma modular en `src/`.
